# Machine Learning Algorithms Collection

A compact collection of classic machine learning projects and notebooks demonstrating core algorithms and workflows. Each folder contains a focused notebook, dataset (where applicable), and a short README.

---

## Projects (quick index)

- **GMM** — *GMM Model implementation*  
  Gaussian Mixture Models for density estimation and clustering.

- **KNN** — *Wine Classification using KNN*  
  k-Nearest Neighbors classification applied to wine dataset.

- **K_Means** — *Customer Segmentation using K-Means*  
  Unsupervised customer segmentation and elbow/ silhouette analysis.

- **Linear_Regression** — *CO₂ Emissions Prediction Analysis*  
  Regression analysis to predict CO₂ emissions, feature engineering and evaluation.

- **Logistic_Regression** — *Iris species classification using Logistic Regression*  
  Classic multiclass logistic regression on the Iris dataset with metrics and confusion matrix.

- **Neural_Network** — *SLP/MLP notebook for multi-layer perceptron*  
  Single-layer and multi-layer perceptron implementations and experiments.

- **SVM** — *SVM Model implementation*  
  Support Vector Machine models (linear & kernel) for classification tasks.
