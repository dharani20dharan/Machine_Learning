# Machine Learning Projects

---

## 1. Movie Recommendation System
A content-based and collaborative filtering system to suggest movies to users based on ratings and similarities.

**Features:**
- Analyze user ratings and movie metadata.
- Generate movie recommendations using collaborative and content-based filtering.
- Visualize popular movies and rating distributions.

**Technologies:**
- Python, Pandas, Numpy
- Scikit-learn
- Matplotlib, Seaborn

---

## 2. Search Engine and Recommendation System (Amazon Products)
Builds a search and recommendation system for Amazon products using customer reviews.

**Features:**
- Explore Amazon review dataset.
- Build search functionality for products based on review text.
- Apply sentiment analysis for better recommendations.
- Visualize review distributions by product ratings.

**Technologies:**
- Python, Pandas, Numpy
- NLTK
- Matplotlib, Seaborn
- Transformers (Hugging Face), PyTorch

---

## 3. Sentiment Analysis
Analyzes text data to determine sentiment using both rule-based and transformer-based approaches.

**Features:**
- Tokenization, POS tagging, and named entity recognition using NLTK.
- Sentiment scoring with VADER.
- Advanced sentiment analysis using RoBERTa transformer model.
- Compare and visualize results from both methods.
- Predict sentiment for new text using a Hugging Face pipeline.

**Technologies:**
- Python, Pandas, Numpy
- NLTK
- Matplotlib, Seaborn
- Transformers (Hugging Face), PyTorch

---

## Overall Outcome
These projects showcase **data preprocessing, NLP, visualization, and recommendation techniques**. They provide a strong foundation for building intelligent systems that analyze user data, extract insights, and offer personalized suggestions.
